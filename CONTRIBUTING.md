# Contributing

Thanks for helping build Poetics. Humans and agents follow the same rules:

1. Read [`AGENTS.md`](AGENTS.md): commands, tests, commit format, and how to
   record your change in `.poetics/`.
2. Read [`docs/getting-started.md`](docs/getting-started.md) to set up.
3. Open an issue first for anything large, or label it `question` if it is a
   design question; it will be closed by a decision record.
4. Pull requests need passing CI and, if a package changed, a changeset
   (`pnpm changeset`).

Found a pitfall? Add it to [`GOTCHAS.md`](GOTCHAS.md).
